Forecasts the Twitch viewers of the Grand Theft Auto VI category for each hour 2–24 of its release day (2026-11-19 UTC), as five quantiles per hour, from the hour-1 print and the release-day curves of past big game launches, re-fit at run time from the case's own comparables.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
